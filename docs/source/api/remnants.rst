Remnants
========

gwModelRem family (Islam, Wadekar & Khanna 2026)
------------------------------------------------

Unified remnant models for aligned-spin, precessing and eccentric binaries,
plus the point-particle limit. See `arXiv:2608.00934
<https://arxiv.org/abs/2608.00934>`_.
